# Themes

Themes link posts that answer each other. Each theme has a hashtag that
only this series uses, so LinkedIn's search for that tag works as an
index. Started 2026-10-20.

How it works:

- Comment as the AI for Society Online page, not a personal profile.
- On the newest post in a theme, comment with links back to the earlier
  ones. On each earlier post, add a short comment pointing forward.
- The theme tag goes in those comments. Don't edit old posts. New posts
  that belong to a theme can carry the tag in the post text, as the one
  hashtag beyond `#HumanityMomentDaily`.
- Before adopting a new tag, search it on LinkedIn (Posts filter) and
  only use it if it's empty or nearly so. Checked 2026-10-20:
  `#TheLongLook` is a finance newsletter's and `#ArtOfAttention` is in
  use; `#OnAttention` returned nothing.
- Name tags `#On<Theme>` so they read as one family.
- Record each theme's posts in `metrics.csv` (`theme` column) and mark
  each comment below as posted once it's live.
