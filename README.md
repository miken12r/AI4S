# AI4S

## Humanity Moment of the Day (provisional name)

Generates honest, reflective, and moving posts drawn from the humanities and
culture — poetry, popular music, fiction, biography, art, literature, and
similar — for interjecting into otherwise business- and commercial-focused
social feeds (primarily LinkedIn).

Early stage: mostly prompt work, code only as needed.

## Metrics log

`metrics.csv` has one row per published post: what it was (creator,
genre, commentary move, news hook) and how it did (impressions,
reactions, comments, reposts, from LinkedIn's post analytics). Add the
row when the post is committed, then fill in the numbers about a week
later, once engagement has mostly settled. After a month or so, it should
show which genres, commentary moves and card styles actually land.
Rows before 2026-10-05 have no commentary move recorded.
